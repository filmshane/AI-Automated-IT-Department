9) HOW THE BOARD WORKS (SHORT)
--------------------------------------------------------------------------------
  1. Hourly cron collects metrics for all hosts in /etc/ansible/hosts.
  2. Prefer Zabbix API on smczabbixp01p (CPU, mem, disks, uptime).
  3. If not in Zabbix: ICMP/SSH probe, then Ansible or direct SSH script.
  4. Results written to data/latest.json.
  5. Board at :8088 shows one tile per host (short name).
  6. Colors:
       green  = ok
       red    = critical (CPU/mem/disk thresholds)
       black  = down/off (no ping, SSH closed)
       purple = ansible_fail (host up, collection failed) — click for details
  7. Click tile = popup stats + uptime.
  8. Click disk row = cleanup advisory (tmp/logs first; DB files never listed).
